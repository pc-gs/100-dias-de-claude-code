# Dia 1/100 — Instalar o Claude Code e fazer o primeiro pedido útil

<!-- ![Dia 1](../../assets/dia-01.png) -->

## 💡 Ideia
O Claude Code corre no terminal, dentro do teu projeto. Lê os ficheiros, propõe alterações e pede autorização antes de mexer. Hoje é só pô-lo a andar e ver o que faz com código a sério.

## 🧪 Teste (15 min)
1. Instala (macOS/Linux): `curl -fsSL https://claude.ai/install.sh | bash`. Windows e outras opções estão no guia oficial.
2. Entra na pasta de um projeto e corre `claude`. Na primeira vez faz login.
3. Pede: `Explica-me o que este projeto faz e onde está o ponto de entrada.`

🏠 **Projeto pessoal:** usa um repo teu antigo de que já não te lembras bem.
💼 **Trabalho:** usa um serviço que conheces mal. Confirma antes se a empresa permite.

## ✅ Correu bem se
A explicação bate certo com o código e apanhaste pelo menos uma coisa que não sabias.
