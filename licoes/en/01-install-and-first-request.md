# Day 1/100 — Install Claude Code and make your first useful request

<!-- ![Day 1](../../assets/dia-01.png) -->

## 💡 Idea
Claude Code runs in your terminal, inside your project. It reads files, suggests changes and asks before touching anything. Today the goal is just getting it running and seeing what it does with real code.

## 🧪 Test (15 min)
1. Install (macOS/Linux): `curl -fsSL https://claude.ai/install.sh | bash`. Windows and other options are in the official guide.
2. Go to a project folder and run `claude`. Log in the first time.
3. Ask: `Explain what this project does and where the entry point is.`

🏠 **Personal project:** pick an old repo of yours you barely remember.
💼 **Work:** pick a service you don't know well. Check your company allows it first.

## ✅ Success check
The explanation matches the code and you learned at least one thing you didn't know.
