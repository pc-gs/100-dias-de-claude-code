# Contribuir / Contributing

- 💡 Sugere uma lição: abre uma issue com o modelo "Sugere a próxima lição".
- 🔗 Recursos: PR para `RECURSOS.md`, só links **grátis**, com uma linha de descrição.
- 🐞 Erros ou links partidos: abre uma issue.

Suggestions in English are welcome too. Contributors are credited in the README.
