## 🇵🇹 Português

Sou dev e quero aprender Claude Code a sério. Em vez de ver vídeos de três horas, faço uma lição curta por dia útil, testo-a e escrevo aqui o que correu bem e o que correu mal.

> ⚠️ Projeto pessoal e **não oficial**. Não tem ligação à Anthropic. Claude e Claude Code são marcas da Anthropic.

### Como funciona
Uma lição por dia útil. Há folgas e, de vez em quando, uma semana de recap. Cada lição tem:

- 💡 **Ideia:** o conceito em poucas linhas.
- 🧪 **Teste:** 🏠 num projeto pessoal e 💼 no trabalho.
- ✅ **Correu bem se:** como sabes que resultou.
- 🐛 **O que me aconteceu:** um problema real e como o resolvi.
- 🔗 **Links grátis:** docs oficiais, cursos e vídeos.
- 🏷️ **Versão testada:** o Claude Code muda todas as semanas.

## 🇬🇧 English

I'm a developer learning Claude Code properly. One short lesson per working day: I test it and write down what worked and what didn't.

> ⚠️ Personal, **unofficial** project. Not affiliated with Anthropic. Claude and Claude Code are trademarks of Anthropic.

Each lesson has: 💡 idea, 🧪 test (🏠 personal project / 💼 work), ✅ success check, 🐛 what happened to me, 🔗 free links, 🏷️ version tested. Rest days and recap weeks included.

English lessons are in [`licoes/en/`](licoes/en/). Share your results with **#100DiasDeClaudeCode #ClaudeCode**, and [suggest the next lesson](../../issues/new/choose) in an issue.
